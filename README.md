# Curso Python — De cero a POO

Proyectos desarrollados durante mi aprendizaje de Python desde cero hasta Programación Orientada a Objetos.

## Proyectos

| Archivo | Descripción |
|--------|-------------|
| `Adivina_el_numero.py` | Juego con bucles, condicionales y random |
| `calculadora_modular.py` | Calculadora con funciones y lambdas |
| `Gestor_Contactos.py` | CRUD con listas, diccionarios y archivos |
| `Biblioteca.py` | Sistema POO con clases, herencia y persistencia |

## Temas aprendidos

- Variables, tipos de datos y operadores
- Control de flujo: if/elif, while, for
- Funciones, parámetros y lambdas
- Listas, diccionarios, tuplas
- Manejo de archivos y excepciones
- Programación Orientada a Objetos

## Tecnologías

- Python 3.x
- VS Code
